
# QA Buddy 🧪

QA Buddy is a beginner-friendly software testing dashboard built with HTML, CSS, and JavaScript.

## Features

- Add test cases with expected results
- Mark tests as passed or failed
- View total, passed, and failed test counts
- Delete test cases
- Automatically save test cases using browser local storage
- Responsive, clean interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## What I Learned

- Working with JavaScript functions and DOM manipulation
- Handling user input and events
- Updating dashboard statistics dynamically
- Saving and loading data with local storage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start adding test cases!
